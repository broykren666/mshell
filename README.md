# MShell 一键管理脚本说明文档

这是一个专为 Linux 服务器设计的自动化部署与管理工具集，支持 Hysteria2、TUIC 和 VLESS-Reality 协议。脚本针对安全、稳定性和易用性进行了深度优化。

---

## 系统要求

- **操作系统**：Debian 11+, Ubuntu 20.04+, Alpine Linux。
- **权限**：必须以 `root` 用户运行。
