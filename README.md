# Hysteria2 一键管理脚本使用说明

这是一个专为 Linux 服务器设计的 Hysteria2 (Hy2) 自动化部署与管理脚本。基于原作者项目进行了安全增强与功能优化，支持一键安装、配置查看、端口修改及防火墙自动同步。

## 🔗 项目来源
*   **原项目作者**: [a88wyzz](https://github.com/a88wyzz)
*   **原项目地址**: [Alpine-Debian-Ubuntu-Hy2](https://github.com/a88wyzz/Alpine-Debian-Ubuntu-Hy2)

---

## 🚀 快速开始

### 1. 下载并运行
在你的服务器上执行以下命令（推荐使用此方式以支持快捷键）：
```bash
wget -O hy2.sh https://raw.githubusercontent.com/broykren666/mshell/refs/heads/main/hy2.sh && chmod +x hy2.sh && ./hy2.sh
```
*注：Alpine 用户如果提示命令不存在，请先执行 `apk add --no-cache wget bash`*

### 2. 管理命令
安装完成后，你可以在任何地方通过输入快捷键直接进入菜单：
```bash
hy2
```

## ✨ 优化版新增功能

- **安全强密码**：默认生成 24 位强随机密码（12字节十六进制），支持手动自定义。
- **智能依赖预检**：自动补齐 `jq`, `curl`, `openssl` 等工具，避免运行报错。
- **防火墙深度同步**：同时支持 `UFW` 和 `iptables`，在**更改端口**或**卸载**时会自动清理冗余规则。
- **快捷键支持**：自动创建 `hy2` 命令，无需记忆繁琐的脚本路径。
- **架构扩展**：新增对 ARMv7 (32位) 架构的支持。

## 🛠 菜单选项说明

1.  **安装 Hysteria2**：开始全新安装。流程中可自定义端口和密码（回车即使用推荐的安全值）。
2.  **查看配置节点链接**：显示 IP、端口、密码，并生成可直接导入客户端的 `hy2://` 链接。
3.  **更改监听端口**：修改服务端口，并同步更新防火墙策略。
4.  **重启服务**：手动重启服务端。
5.  **卸载 Hysteria2**：彻底清理服务、配置、防火墙规则及快捷键。

## 📋 系统要求

- **操作系统**：Debian 11+, Ubuntu 20.04+, Alpine Linux。
- **权限**：必须以 `root` 用户运行。

## ⚠️ 注意事项

- 脚本默认使用自签证书，客户端连接时需开启 `insecure: true`（脚本生成的链接已包含此参数）。
- 伪装域名默认为 `www.bing.com`，如有需要可在脚本顶部的 `SERVER_NAME` 参数中修改。
